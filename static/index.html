批量人工审核

与 Codex / harness 交接

工作台保存任务与证据，外部工具提交可追溯的审核意见。

  1. 完成一轮采集

    演示数据与真实批次分别标注。批次完成后导出 JSON，包含证据快照及审核格式。

  2. 交给 Codex 筛选

    让它核对原文、身份、重复项与未知信息；输出带 candidate_id、base_version 和理由的审核变更。

  3. 导入后人工复核

    使用“导入审核”，查看三层判断和修改历史。保留、排除、补查均可在 UI 中调整。

本地 HTTP 接口

只在本机提供服务。读取 GET /api/bootstrap 获取 token，写入时使用 X-App-Token；CLI 和 MCP 也通过 HTTP 读写，不直接改数据库。

GET /api/runs批次列表
GET /api/candidates?run_id=…候选与版本
GET /api/candidates/{id}完整证据与判断
POST /api/reviews幂等、版本检查、原子审核
POST /api/reviews/{id}/revert撤销审核变更

MCP 工具包括 runs_list、candidates_list、evidence_get、reviews_submit、reviews_revert、runs_start、runs_pause。启动与命令行说明见随程序 README。

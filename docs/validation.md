# 验证范围与已知限制

以下是 **0.5.3** 的开发验证记录，用于说明证据强度，不代表已经完成真实账号采集、模型效果或获客转化验证。

## 仓库内可以运行的测试

在仓库根目录，使用 Python 3.12：

```powershell
python -m unittest discover -s tests -v
```

0.5.3 已记录 **182 项后端测试通过**，其中包含 30 项任务生命周期专项测试，另包含开源通用默认值与已有配置保留的兼容检查。当前测试数量应以实际命令输出为准。

这些测试覆盖存储和 HTTP 契约、有限批次执行、处理模式、平台命令和结果映射、评论身份和去重、目标条件、批量统计、审核版本和撤销、CLI/MCP 协议及生命周期操作。网络和模型边界主要使用本地 fixture 或模拟响应，不要求真实平台账号。

任务生命周期验证包括原子批量移入／恢复／永久删除、运行或后台收尾时拒绝操作、恢复后原文与审核一致、关联资料清理、幂等请求重试及已删除任务的读取限制。

## 没有完成的验证

| 范围 | 当前结论 |
|---|---|
| 真实平台登录与读取 | 尚未完成真实登录账号的端到端实站验收；命令源码、帮助和 fixture 通过不能替代实站成功，命令核验基线为 OpenCLI 2.0.2 |
| 快手实验性 DOM | 只核验固定读取规则和接口行为；页面变化后可能失效 |
| 评论完整性 | 仅所选帖子下的有界样本；没有全站评论索引或完整遍历承诺 |
| 本地模型效果 | 适配和调用边界有 fixture 验证；没有对任意模型的准确率、速度、长上下文或硬件容量作保证 |
| 获客和成交结果 | 未验证真实买方身份、可达性、订单或交易转化 |
| 其他操作系统 | 当前主要验证 Windows；没有据此宣称各平台桌面兼容性已完成验收 |

演示任务和文档截图使用合成资料，不应作为真实来源或客户成果。公开网页可读也不意味着相同站点、登录状态和网络环境下一直可读。

## 建议的独立验收顺序

1. 在新数据目录启动程序，运行合成演示；确认演示标记、原文阅读、审核和导出正常。
2. 导入少量自己有权使用的原文，选择 `collect_only`，确认模型离线时仍可处理，并保留原链接和正文。
3. 使用临时合成任务检查移入回收站、恢复和永久删除；不要用正式资料做删除测试。
4. 自行启动本地模型，测试连接后用少量已核对的样本检查角色、引用和未知字段。确认整批处理进度和人工审核仍相互独立。
5. 配置 OpenCLI／Browser Bridge 和相应登录，以少量只读任务核对原文、链接、部分结果和错误状态。登录或读取失败不能归类为没有需求。

验证生产模型或平台时应另行记录版本、配置、样本范围和结果，避免把模拟响应混记成真实运行。

## 贡献时需要保持的边界

- 桌面、CLI 和 MCP 的业务写入统一走本地 HTTP API，不能绕过审核版本或直接改原始证据。
- `collect_only` 不得调用模型规划或分析；合成任务不得伪装成真实推理或真实客户。
- 来源采集保持只读；不能通过类似 `comment` 的命令名称猜测读写能力。
- 任务生命周期保持原子、幂等和运行状态保护；恢复不自动运行。
- GUI 网络、文件读取和较重解析留在后台，原文作为纯文本显示。
- 测试、截图、日志和示例不应包含真实账号、密钥、本地实例 token 或未经授权的业务资料。

接口以 [API_CONTRACT.json](../API_CONTRACT.json) 为准；模块与数据流程见 [architecture.md](architecture.md)。

CLI/MCP client, bounded collection and review workflow, source tests, Windows build
scripts and third-party notices. The follow-up pull request adds Windows backend CI,
an optional manual Qt import check, contribution and security reporting guidance, and
this session reference.

Before publication, 182 backend fixture tests passed locally. Published fixtures and
screenshots use synthetic examples. Tests do not establish real-platform collection,
live-model quality or sales outcomes. See [validation boundaries](validation.md).

Runtime databases, accounts, authentication tokens, imported business evidence,
local model files, private deployment notes and generated executables are excluded.
